# SunCode 自身知识

先读取系统提示 `context.projectKnowledge.entryPath` 指向的运行时文档。它提供当前模型、工作目录、实际全局约束路径、应用数据目录和内置文档索引。动态路径以该文件为准，不按操作系统或安装位置猜测。若运行时入口未提供或读取失败，说明缺失的信息，按需读取本 skill 相对路径 `../../docs/project-info.md`；不要声称已经确认动态配置。

当前工作目录是用户正在处理的项目，未必是 SunCode 源码。已有明确路径或文档答案时，直接处理请求，不再搜索安装包、历史会话或其他项目来重复确认。

## 全局用户约束

用户要求添加、修改或查看全局约束时，使用运行时文档中的“全局用户约束文件”，即用户主目录下的 `~/.suncode/AGENTS.md`，不是源码目录或安装目录。

1. 读取该文件；明确不存在时可创建（包括缺失的 `.suncode` 父目录），权限或其他读取错误不能当作空文件处理。
2. 按请求合并规则，保留无关内容，避免重复添加；只有会影响结果的规则冲突才向用户澄清。
3. 写入后回读确认，报告保存位置及后续新运行会自动加载。文件尚未创建不代表不支持全局约束。

这是所有项目自动加载的指令，不是按相关性检索的记忆。不要把全局约束写入当前项目的 AGENTS.md，或自动修改其他产品的配置。仅查看或诊断时不写入文件。
